# 资料集治理与企业生产标准

这份规则用于判断“资料很多”是否真的可以支撑研究、教学和企业内部生产。资料库按来源和证据等级管理，不把数量当成质量。

## 资料分层

| 层级 | 内容 | 允许支撑的结论 | 必须保留的元数据 |
| --- | --- | --- | --- |
| A：官方产品/算法规范 | USGS、NASA、ESA、Google Earth Engine、GDAL、Sen2Cor 等官方手册 | 波段、缩放、QA、产品定义、处理边界 | 发布方、版本、URL、发布日期/访问日期、许可、SHA-256 |
| B：开放获取论文全文 | 可访问 PDF 且 DOI/来源可核验 | 公式、方法、实验设计、误差和验证指标 | DOI、作者、期刊、PDF URL、许可状态、SHA-256 |
| C：论文候选元数据 | OpenAlex/Semantic Scholar 题目、摘要、DOI | 发现文献、建立收集清单 | API、查询式、记录 ID、抓取时间、摘要是否完整 |
| D：代码与工具文档 | IDL/ENVI、GDAL、Rasterio、GEE、STAC 示例 | API 用法和可执行实现草稿 | 版本、运行环境、仓库/文档 URL、许可证 |
| E：内部资料 | 学校/企业上传的私有资料 | 仅在授权租户内使用 | 所有者、访问范围、保留期限、删除记录、版本 |

## 入库闸门

每个文件进入生产知识库前必须通过：

1. 文件类型和大小检查；PDF 必须能解析出文本或明确标为 OCR。
2. SHA-256 计算；同一来源的内容变化必须产生新版本，而不是覆盖旧文件。
3. 来源和许可字段完整；没有来源的文本只能进候选区。
4. 文档标题、章节、页码或代码行号可定位；引用不能只指向一个模糊文件名。
5. 解析后抽查公式、单位、QA 位、缩放因子、代码块和表格。
6. embedding 使用当前生产模型重新建立；禁止 fallback 向量进入生产库。
7. 每个知识库通过 Golden QA 检索评测，并保留失败样例。

## 论文许可政策

“OpenAlex `is_open_access=true`”只说明 OpenAlex 判断存在开放访问位置，不自动等于允许再分发。下载器因此只把论文存放在本地研究资料目录，manifest 记录 `license_status`，默认值为 `redistribution_terms_must_be_verified`。只有确认 CC、政府公共领域或期刊明确许可后，才可以进入面向其他用户的下载包。

## 版本和刷新

- 官方产品目录：每月检查一次页面变更和数据集状态。
- 工具文档：每个软件大版本发布时重新抓取；旧版本保留用于可复现实验。
- 论文候选库：每周增量搜索；全文库只在 DOI、许可和 SHA 校验通过后晋级。
- 内部资料：按组织的保留策略刷新；删除必须记录操作人、时间和影响范围。

## 生产发布条件

资料集只有同时满足以下条件才能标记为 `production_ready`：

- 所有文档完成索引，queued/processing/stale/failed 为 0；
- fallback embedding 为 0，且文档模型、维度和索引表签名一致；
- 官方资料和论文全文都有可追溯来源；
- Golden QA 命中率、引用覆盖率、拒答率和失败样例达到项目阈值；
- 关键任务至少用一个独立小样本运行，保存输入、公式/参数、代码、输出影像和环境信息；
- 备份恢复、访问隔离、删除和审计日志经过演练。

生产闸门未通过时，界面必须明确显示“可试用/不可作为正式结论”，不能只显示一个绿色的“已完成”。
